
# 🍦 Kones Gourmet - Central da Silvia

Silvia, use estas instruções se precisar colocar o site no ar em um novo lugar!

## 🚀 Opção 1: Vercel (Recomendado)
A Vercel é mais simples e rápida que a Cloudflare.

1. Acesse [vercel.com](https://vercel.com) e conecte com seu GitHub.
2. Clique em **"Add New Project"**.
3. Selecione o projeto `kones-gourmet-cardapio`.
4. Clique em **"Deploy"**.
5. Quando terminar, você ganhará um link como: `kones-gourmet.vercel.app`.

## ☁️ Opção 2: Cloudflare Pages
Se preferir a Cloudflare:

1. Acesse [pages.cloudflare.com](https://pages.cloudflare.com).
2. Conecte ao GitHub e escolha o projeto.
3. Se aparecer **"Nenhuma URL habilitada"**, espere 5 a 10 minutos. É o tempo que eles levam para ligar o servidor.

## ⚠️ Dica das Fotos
Se o site ficar lento ou parar:
- Suas fotos podem estar muito pesadas. 
- Use o site [TinyPNG.com](https://tinypng.com) para diminuir o tamanho das fotos antes de colocar no cardápio.
