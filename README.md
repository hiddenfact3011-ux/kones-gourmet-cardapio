
# 🍦 Kones Gourmet - Cardápio Digital (Silvia)

Silvia, este é o seu cardápio profissional! Se a Netlify pausou seu site, não se preocupe. Vamos mudar para a **Cloudflare**, que é mais rápida e gratuita de verdade.

## 🚀 Como colocar no ar agora (Grátis e Ilimitado)

Recomendo usar a **Cloudflare Pages** para nunca mais ter o site pausado:

1.  Acesse [pages.cloudflare.com](https://pages.cloudflare.com/) e crie sua conta (ou faça login).
2.  Clique em **"Connect to Git"**.
3.  Selecione o seu GitHub e escolha o projeto: `kones-gourmet-cardapio`.
4.  Nas configurações de instalação:
    *   **Framework preset**: Escolha `Vite`.
    *   **Build command**: `npm run build`
    *   **Build output directory**: `dist`
5.  Clique em **"Save and Deploy"**.

Pronto! Em 2 minutos você terá um novo link (ex: `kones-gourmet.pages.dev`) que não cai!

---

## 📸 Dica Crucial: Suas Fotos estão "pesadas"?

Se o site pausou, pode ser porque as fotos que você tirou no celular são muito grandes (ex: 5MB cada). 

**Para o site nunca mais travar:**
1.  Antes de subir uma foto no painel da Silvia, passe ela no site [TinyPNG.com](https://tinypng.com/).
2.  Ele vai diminuir o peso da foto (ex: de 5MB para 200kb) sem perder a qualidade.
3.  Isso faz o site abrir instantaneamente no celular do cliente!
